## 🚀 Quick Start / How to Run

### Method 1: Direct File Opening
Double-click [**`index.html`**](file:///e:/Auto/Agastya/index.html) to open directly in any browser (Chrome, Edge, Safari, Firefox). No build step required!

### Method 2: Node.js Built-in Server
Run the local server using Node:
```bash
npm start
```
or
```bash
node server.js
```
Then visit: **`http://localhost:3000`**
